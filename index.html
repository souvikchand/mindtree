Instructions

  • Add Root Node: Click "Add Root Node" to create the main node
  • Add Child: Select a node (click on it) then click "Add Child Node"
  • Edit: Double-click on a node to edit its text and color
  • Delete: Select a node and click "Delete Node"
  • Move: Drag nodes to reposition them
  • Save/Load: Save your tree to browser storage or export as JSON
